# DrumMachine
Vamos a hacer el proyecto con vite. Acuerdate que para instalar vite debes poner en la terminal:
```
npm create vite@latest
```
Despues tenemos que entrar en la carpeta del proyecto y colocar:
```npm run dev
```
## Boostrap
Simplemente instalamos boostrap colocando en la terminal:
```
npm install bootstrap

o
npm i bootstrap
```
Despues en App.jsx importamos el css de boostrap:
```js
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';
```
